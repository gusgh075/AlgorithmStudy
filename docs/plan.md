# 🔥 너가 지금부터 풀면 좋은 문제 유형 TOP 5

## 1️⃣ **구현 + 시뮬레이션(빡구현) 난도 업그레이드**

너 지금 시뮬 일부 풀이 경험 있는데, **카카오 기출 레벨 시뮬**을 제대로 파면 실력 확 찐다.

➤ 추천

* 카카오 기출 전체 (2018–2024)
* BOJ 골드 2~1 구현 문제
* 백준 23290(마법사 상어와 복제), 21610(구름과 비바라기), 19237(어른 상어)

이건 진짜 “어지러운데 결국 푸는” 경험을 쌓는 게 핵심.

---

## 2️⃣ **투 포인터 & 슬라이딩 윈도우 완전 정복**

너 리스트에 투포인터 계열 문제 거의 안 보임.
기업 코테에서 미친 듯이 자주 나온다.

➤ 추천

* BOJ 2003 수들의 합
* BOJ 2531 회전초밥
* BOJ 20922 겹치는 건 싫어
* LeetCode 투포인터 전형 문제들

---

## 3️⃣ **트리 DP + 그래프 DP**

DP는 많이 했는데, **트리 기반 DP**나 **그래프 위 DP**는 안 보여.

이쪽은 면접에서도 개념 많이 물어보고 실코테에서도 갑자기 낼 수 있어.

➤ 추천

* BOJ 15681 트리와 쿼리
* BOJ 2533 사회망 서비스(SNS)
* BOJ 1949 우수마을
* BOJ 12869 뮤탈리스크(그래프 DP)

---

## 4️⃣ **우선순위 큐 + 그래프 확장 문제**

다익스트라, 0-1 BFS 이런 거 실전에서 자주 나온다.

너 BFS/DFS 잘하는데, 다익스트라 계열이 좀 부족해 보여.

➤ 추천

* BOJ 1504 특정한 최단 경로
* BOJ 1261 알고스팟(아 이미 풀었네!!) → 그럼
* BOJ 1753 최단경로
* BOJ 13549 숨바꼭질 3

이 계열은 카카오, 라인, 네이버 코테에서 거의 단골.

---

## 5️⃣ **문자열 알고리즘(정규식 말고 KMP, Z, 라빈-카프)**

너 문자열은 구현 수준인데,
기업 코테는 가끔 **패턴 매칭 알고리즘** 지식 요구하는 문제 나옴.

➤ 추천

* KMP 알고리즘 구현 문제
* BOJ 1786 찾기
* Z-algorithm 문제 (BOJ 4354 문자열 제곱)
